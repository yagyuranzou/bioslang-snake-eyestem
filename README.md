BIOSLANG SNAKE EYESTEM

Real-time Kinetic & Audio-Responsive Visual System for Experimental Performance
ライブ・パフォーマンス用・運動響応型ヴィジュアル・システム
1. Project Overview / プロジェクト概要
BIOSLANG SNAKE EYESTEM is a specialized visual instrument designed for experimental electronic music performances. It processes real-time skeletal kinetics and audio input to generate a high-density, data-polluted visual environment, transforming the performer's presence into a live technical glitch stream.

BIOSLANG SNAKE EYESTEM は、実験的電子音楽ライブパフォーマンスのために設計された専用ヴィジュアル楽器です。リアルタイムの骨格運動とオーディオ入力を処理し、高密度な「データ汚染」ヴィジュアル環境を生成します。パフォーマーの存在を、ライブ・テクニカル・グリッチ・ストリームへと変換します。

2. Core Features / 主な機能
Kinetic Data Mapping: Real-time tracking of facial landmarks and limbs, mapped to industrial-style warning frames.

運動データマッピング: 顔面および四肢のリアルタイム追跡。インダストリアルな警告フレームに同期。

Live API Data Injection: Injects live Tezos block heights and NASA telemetry data into the visual layer, creating a "system-overload" aesthetic.

ライブAPIデータ注入: Tezosのブロック高やNASAのテレメトリデータを視覚層に注入し、「システム過負荷」の美学を演出。

Audio-Responsive Feedback: Triggers high-intensity visual alerts and "system panic" states when audio levels hit peak thresholds.

音響応答型フィードバック: 音響レベルがピークに達した際、激しい視覚的アラートと「システムパニック」状態をトリガー。

High-Density Glitch Overlay: A custom data-pollution engine that renders streaming variables at high frequency to simulate a dying terminal.

高密度グリッチ・オーバーレイ: 独自のデータ汚染エンジンにより、変数を高頻度でレンダリングし、崩壊するターミナルをシミュレート。

3. Performance Setup / パフォーマンス設定
Environment: Run the snake_eyestem.html file in a Chrome/Edge browser on the main performance computer.

環境: パフォーマンス用コンピュータのChrome/Edgeブラウザで snake_eyestem.html を実行してください。

Setup: Ensure the camera has a direct view of the performer. Connect the main audio output via an audio interface to drive the visual response.

セットアップ: カメラがパフォーマーを捉えていることを確認してください。メインのオーディオ出力をオーディオインターフェイス経由で接続し、ヴィジュアルの応答を駆動させます。

Execution: Click the screen to initialize. The system will auto-lock on the performer’s skeletal structure.

実行: 画面をクリックして初期化。システムが自動的にパフォーマーの骨格構造をロックオンします。

4. Technical Specifications / 技術仕様
Tracking Engine: Mediapipe Holistic (Face, Left Hand, Right Hand).

追跡エンジン: Mediapipe Holistic (顔、左手、右手)。

API Dependencies: Real-time fetching from TzKT API and NASA telemetry endpoints.

API依存関係: TzKT API および NASA テレメトリエンドポイントからのリアルタイム取得。

Rendering: Dual-layer Canvas (Skeleton Layer / Data Glitch Layer).

レンダリング: 2層 Canvas (骨格層 / データ汚染層)。


How to Use / 使用方法
Launch: Open the index.html file in a modern web browser.

起動: index.html ファイルをモダンなウェブブラウザで開いてください。

Permissions: Click anywhere on the screen to grant camera and microphone access to initiate the terminal.

権限: 画面の任意の場所をクリックして、カメラとマイクのアクセス許可を与え、ターミナルを初期化してください。

Monitoring: The system will automatically lock onto detected subjects and start the logging stream.

監視: システムは自動的に被検者をロックオンし、ログストリームを開始します。

Technical Requirements / 技術要件
Web Browser: Chrome or Edge (recommended for Mediapipe compatibility).

ウェブブラウザ: Chrome または Edge (Mediapipe の互換性のため推奨)。

Hardware: Webcam and Microphone.

ハードウェア: ウェブカメラとマイク。
